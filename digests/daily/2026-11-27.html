OneQuery: Unified Sequence-to-Structure Generation for Multilingual E-commerce Query Understanding

21h ago
Figure 2. Three-Stage Training Framework of OneQuery.

Multilingual e-commerce search requires robust query understanding, but traditional pipelines suffer from error accumulation and high maintenance costs due to separately optimized subtasks. To solve this, the authors propose OneQuery, a unified generative framework that reformulates language recognition, spelling correction, translation, and query tagging into a single schema-guided sequence-to-structure generation task. The approach relies on a progressive three-stage training pipeline: joint single-task SFT, data synthesis via iterative field completion, and task-aware multi-objective reinforcement learning alignment using GRPO. Experiments on AliExpress data show consistent performance gains over traditional pipelines across 4B, 8B, and 14B model scales, outperforming few-shot proprietary LLMs. Online A/B tests further confirm practical business impact with improved conversion and relevance metrics.

Key ideas
1 Reformulate language recognition, spelling correction, translation, and query tagging into a unified sequence-to-structure JSON generation task using domain-specific large language models.
2 Implement an Iterative Field Completion data synthesis strategy to generate 3.6 million fully annotated training samples from partially annotated task-specific data.
3 Use a progressive three-stage training pipeline combining joint single-task SFT, hybrid dataset fine-tuning, and task-aware multi-objective RL alignment (GRPO) with rule-based rewards.
4 Design task-aware rule-based rewards (including exact match and edit distance similarity) with non-uniform weights to balance gradient contributions and mitigate multi-task optimization conflicts.
📊 Results
Evaluated on 19,087 multilingual search queries from AliExpress, the 14B model improved Language Recognition accuracy from 0.9514 to 0.9665, Translation ROUGE-2 from 78.20 to 80.50, Spelling Correction F1 from 0.8568 to 0.8717, and Query Tagging F1 from 0.8128 to 0.8366. Online A/B tests on AliExpress showed a 0.5% improvement in list-to-payment conversion rate (L2P) and a 0.8-point gain in relevance evaluation.
🛍 How to apply at THE ICONIC
  • Adopt the schema-guided sequence-to-structure generation paradigm to unify THE ICONIC's search query understanding pipeline (combining spelling correction, translation, intent, and entity tagging) to reduce error propagation and serving overhead.
  • Apply the iterative field completion and data synthesis strategy to bootstrap a unified query understanding or product attribute extraction model using partially annotated historical logs.
  • Deploy a hybrid serving architecture with large offline-cached models for head queries and a distilled lightweight student model for real-time tail queries to meet strict e-commerce search latency constraints.

Interactive-Active-AI/NextTransformer

31 Oct · ⭐ 500

NextTransformer is an open-source framework, benchmark, and auto-research platform designed to evaluate next-generation Transformer architectures under strictly controlled computational budgets. The framework ensures fair comparisons by training diverse variants—including recurrent depth, sparse and linear attention, residual-stream choices, and hybrids—on identical data tokens and training FLOPs. It features Arena v2 for agent-native research, comprehensive leaderboards, and an extensive model zoo containing baseline, residual, looped, sparse, linear, and hybrid configurations. The main findings provide transparent, audited performance metrics across different architectures to guide efficient language model scaling and design.

Key ideas
1 Fair training protocol enforcing identical data, tokenizers, contexts, and training FLOPs per token to evaluate different transformer architectures objectively.
2 Comprehensive model zoo spanning baseline, residual, looped, sparse, linear, and hybrid architectures sharing a single trainer and data pipeline.
3 Arena v2 framework enabling agent-native autonomous research through a research gym with MCP tools and metered compute.
4 Mixture of Experts (MoE) track evaluating sparse models using MoE-CORE metrics across standardized sizes and token counts.
📊 Results
Models are evaluated across 49.152B input tokens using 46,875 updates, with MoE tracks comparing d768 at 14.07B tokens and d1024 at 34.06B tokens.
🛍 How to apply at THE ICONIC
  • Leverage alternative transformer architectures like linear attention or hybrid models from the model zoo to optimize latency and efficiency for e-commerce product recommendations or search ranking.
  • Adopt the strict compute-matching and evaluation protocol principles to fairly benchmark custom language models or recommendation algorithms against internal baselines.

eust-w/opengeniemaster

27 Oct · ⭐ 502

OpenGenieMaster is an open-source embodied continuous harness designed for continuous multi-robot operations, replicating the GenieMaster framework without modifying policy weights. It utilizes an Embodied Execution Protocol (EEP) exposed as an MCP server to allow coding agents like Claude Code or Codex to call robot capabilities, provide multimodal guidance, read physical feedback, and resume interrupted tasks. The system incorporates shared admission safety interlocks, versioned long-term memory with reflection, and a semantic multi-robot simulator. According to the benchmark results, the system achieves a 93.2 percent overall success rate and maintains high generalization on novel items.

Key ideas
1 Implement EEP over MCP to expose robot capabilities, multimodal guidance, and task continuity directly to coding agents via standard stdio.
2 Maintain task continuity by binding work items to robots with dependencies and state persistence, enabling resumption from the next incomplete step after interruption.
3 Enforce safety through shared admission interlocks that reject requests if robots are stopped, calibration fails, dependencies are unmet, or humans enter the workspace.
4 Reflect execution records into versioned, diffable, and rollbackable long-term memory without altering underlying policy weights.
📊 Results
In the built-in semantic simulator across 6 tasks and 100 trials per method, OpenGenieMaster achieved an overall success rate of 93.2 percent compared to 12.5 percent for end-to-end VLA.

HiGR: Industrial-Scale Hierarchical Generative Slate Recommendation Framework in Tencent

6 Nov · 17 citations

Slate recommendation systems typically rely on multi-stage pipelines that process items in isolation, causing a disconnect between token-level generation and holistic slate quality. To solve this, the authors propose HiGR, an industrial-scale hierarchical generative framework for slate recommendation developed by Tencent. HiGR introduces a Prefix-Contrastive Residual Quantized VAE (PCRQ-VAE) to learn structured semantic IDs, a Hierarchical Slate Decoder (HSD) for coarse-to-fine generation that reduces latency, and an ORPO-based listwise preference alignment mechanism for triple-objective optimization. Offline experiments and online A/B tests demonstrate that HiGR outperforms state-of-the-art baselines by over 10% in recommendation quality while achieving a 5x inference speedup and significant online engagement gains.

Key ideas
1 Use Prefix-Contrastive RQ-VAE (PCRQ-VAE) with contrastive constraints on the first D-1 codebook layers to enforce semantic prefix alignment while reserving the final layer for fine-grained item discrimination.
2 Implement a Hierarchical Slate Decoder (HSD) that separates generation into a coarse-grained slate planner (predicting preference embeddings) and a lightweight shared item generator (decoding SID tokens).
3 Incorporate an intra-list diversity (ILD) regularization term into preference planning to explicitly penalize redundancy among planned items without post-hoc filtering.
4 Apply Odds Ratio Preference Optimization (ORPO) for reference-free listwise preference alignment, constructing negative slates targeting ranking fidelity, genuine interest, and diversity.
📊 Results
HiGR was evaluated on a 1-billion-sample industrial dataset from Tencent and the KuaiRec dataset, outperforming baselines by over 10% in offline recommendation quality with a 5x inference speedup. Online A/B tests on Tencent platforms showed a 1.22% increase in watch time and a 1.73% increase in video plays.
🛍 How to apply at THE ICONIC
  • Apply HSD coarse-to-fine generation to homepage tile personalisation and category page slate generation to jointly optimize list-level diversity and relevance instead of independent item scoring.
  • Adapt PCRQ-VAE semantic tokenisation to catalog product data, using prefix-level contrastive alignment to improve category-aware product embeddings for visual search and recommendations.
  • Use ORPO-based listwise preference alignment to fine-tune generative recommendation models on multi-objective implicit feedback like conversion rates, basket size, and fashion style diversity.

Mining Customer Reviews for Product Improvement Using Aspect-Based Sentiment Analysis and Clustering

18 Nov · Universitas Langlangbuana

Online customer reviews contain valuable feedback, but conventional sentiment analysis assigns a single polarity label to an entire review instead of identifying specific product attributes. This study develops an integrated framework combining aspect-based sentiment analysis and text clustering to identify product attributes, determine aspect-level sentiment, and group customer complaints. The approach translates these complaint patterns into actionable product-improvement recommendations. By processing a large e-commerce review corpus through text cleaning, sentiment classification, semantic embedding, and clustering, the framework extracts granular customer intelligence. The study evaluates the proposed approach using topic coherence, classification accuracy, macro-F1, the Silhouette coefficient, and the Davies-Bouldin Index.

Key ideas
1 Combine aspect-based sentiment analysis with text clustering to isolate specific product attributes and their associated customer sentiment rather than relying on overall review polarity.
2 Utilize semantic text embedding followed by complaint clustering to group related customer grievances into distinct patterns for product improvement.
3 Evaluate framework performance using a mix of NLP and clustering metrics including topic coherence, classification accuracy, macro-F1, Silhouette coefficient, and Davies-Bouldin Index.
📊 Results
The study processed a publicly available e-commerce review corpus containing 27,846 retained reviews.
🛍 How to apply at THE ICONIC
  • Apply aspect-based sentiment analysis and clustering to THE ICONIC customer reviews to automatically extract specific product pain points like sizing, fabric quality, or delivery issues, feeding insights directly to buyers and catalogue quality teams.
