Knowledge graph-based method for product attribute extraction in e-commerce platforms

29 Oct · Tourism and Business College, Hubei Vocational and Technica…

This paper addresses the challenges of data diversity, semantic ambiguity, and long-tail attribute sparsity in e-commerce product data. It proposes a knowledge graph-based framework combining advanced entity and relation extraction with a dual-module knowledge distillation approach. The method leverages a pre-trained language model for entity identification and normalization, alongside feature-based and response-based distillation from a teacher to a student model. Joint optimization is utilized to align cross-modal embeddings and improve robustness against noisy multi-modal data. Experimental results demonstrate superior performance over traditional rule-based, neural sequence labeling, and classical knowledge graph baselines.

Key ideas
1 Combine advanced entity and relation extraction with dual-module knowledge distillation to tackle long-tail attribute sparsity and semantic ambiguity in e-commerce product catalogues.
2 Use a pre-trained language model specifically for identifying and normalizing product entities from unstructured multi-modal data sources.
3 Implement feature-based and response-based distillation to transfer both label-level and representation-level knowledge from a complex teacher model to an efficient student model.
4 Apply joint optimization techniques to enhance cross-modal embedding alignment and increase model resilience against noisy data and domain shifts.
📊 Results
The method was validated on a million-scale real-world product dataset, achieving higher F1 scores and improved generalization to rare attributes compared to traditional rule-based, neural sequence labeling, and classical knowledge graph baselines.
🛍 How to apply at THE ICONIC
  • Adopt the dual-module knowledge distillation approach to compress large language models used for automated product attribute extraction, reducing inference latency for catalogue updates.
  • Leverage the proposed knowledge graph framework and entity normalization techniques to improve long-tail attribute extraction, enhancing search and query understanding for niche fashion items.

AMS-RAG: An Adaptive Multi-Stage Retrieval-Augmented Generation Framework for Intelligent Product Recommendation

5 Nov · Assistant Professor, Department of Computer Applications, V…

Conventional RAG systems rely on single-stage semantic retrieval and often fail to handle structured user constraints like brand, price, and category preferences in e-commerce. This paper introduces AMS-RAG, an Adaptive Multi-Stage Retrieval-Augmented Generation framework designed for intelligent product recommendations. The approach integrates Adaptive Query Understanding, Adaptive Metadata Filtering, Semantic Retrieval, Adaptive Diversity Re-ranking, and Adaptive Confidence Scoring to progressively refine candidate items. The system utilizes Sentence-BERT for embeddings, ChromaDB for vector retrieval, and FLAN-T5 for generating final responses. Experiments show the framework achieves significant search space reduction while maintaining high recommendation precision.

Key ideas
1 Use an Adaptive Query Understanding and Metadata Filtering pipeline to enforce hard constraints like brand, category, price, and ratings before semantic retrieval.
2 Implement an Adaptive Multi-Stage refinement process combining vector search with semantic retrieval, diversity re-ranking, and confidence scoring prior to LLM generation.
3 Leverage Sentence-BERT for generating semantic item embeddings paired with ChromaDB as the underlying vector retrieval store for candidate generation.
4 Employ FLAN-T5 as the underlying generative model to synthesize the final conversational or textual product recommendations based on the filtered candidate set.
📊 Results
Experiments on an Amazon product dataset of 1,465 products demonstrate approximately 98% search space reduction with an average Precision and Hit Rate of 0.90.
🛍 How to apply at THE ICONIC
  • Adopt the multi-stage filtering and re-ranking approach (combining hard metadata filters for fashion attributes like size, brand, and price with semantic vector search) to improve product discovery in search and conversational agent applications.
  • Incorporate adaptive diversity re-ranking into personalized homepage tiles and recommendation carousels to prevent recommendation redundancy and surface a more balanced mix of styles.

BehaviorMem: Building and Evaluating User Memory from Real-World E-Commerce Behavior Streams

26 Oct
Figure 1. Comparison of dialogue-oriented and behavioral user memory across formation, maintenance, and readout. Dialogue memory preserves and organizes information expressed in interactions. Behavioral memory retains behavioral facts and…

Building persistent user memory from implicit e-commerce behavior streams is challenging because interactions record what users did without explicitly explaining their underlying preferences or needs. The authors introduce BehaviorMem, a memory method that organizes explicit behavioral facts and inferred user characteristics across long-term and short-term scopes in a two-axis state. They also develop BehaviorMemBench, a benchmark covering 1,194 users and 17,462 behavioral batches with automatic future-behavior labels to separately evaluate remembering and inference under a common protocol. Experiments show that BehaviorMem consistently leads evaluated agentic memories on both remembering and inference recall measures while using over 70 percent fewer memory tokens. Validation on a public dataset further confirms its usefulness for downstream ranking tasks.

Key ideas
1 Organize memory using a two-axis state pairing explicit programmatic facts with inferred claims, categorized across long-term and short-term temporal scopes to distinguish accumulated tendencies from stage-specific needs.
2 Implement evidence-grounded abstraction moving sequentially from behaviors through patterns and themes to user characteristics, ensuring claims remain anchored to supporting behavioral references.
3 Apply continual maintenance rules that separate local content revision from temporal availability, using retirement only for direct contradiction and allowing paths to become dormant without deleting their evidence.
4 Use a query-independent, model-free readout protocol where explicit facts and active claims are deterministically projected without influence from downstream task queries or candidate pools.
📊 Results
BehaviorMemBench covers 1,194 users and 17,462 behavioral batches over more than three years, containing 913,271 visits and 16,268 history-to-future transitions. BehaviorMem uses over 70% fewer memory tokens than Long Context and LightMem, while achieving top item ranking scores (HR@10 and NDCG@10) on the MemoryCD public dataset.
🛍 How to apply at THE ICONIC
  • Adopt BehaviorMem's two-axis memory architecture to power THE ICONIC's homepage tile personalisation and personal shopping agents by maintaining both explicit product interaction facts and inferred style preferences.
  • Implement BehaviorMem's token-efficient, query-independent readout mechanism to supply compact user context to downstream recommendation and LLM-based query understanding models, reducing input token overhead.

vercel-labs/ui

26 Oct · ⭐ 4.7k (+562 today)

Vercel Labs UI SDK is a library of interface behaviors specifically designed for AI agents to build the next generation of user interfaces. The library provides core primitives like keyboard navigation, focus management, selection, dismissal, popups, and drag and drop under @ui-sdk/core. It includes framework-specific adapters for React, Vue, Svelte, Solid, and Web Components via createParts. Developers can give agents the UI SDK skill using npx skills add to let agents write and assemble UI components. The project is currently in beta under Vercel beta terms.

Key ideas
1 Use @ui-sdk/core for primitive UI behaviors such as keyboard navigation, focus recovery, selection, and ARIA attributes.
2 Integrate framework-specific adapters to render components seamlessly across React, Vue, Svelte, Solid, and Web Components.
3 Equip LLM agents with the UI SDK skill via npx skills add so they can write custom primitives and build interfaces.
4 Construct primitives with explicit state, APIs, and slots to bind behaviors directly to HTML elements and components.
📊 Results
No quantitative results reported.

FERN: Cross-Benchmark Table Retrieval for Text-to-SQL with Frozen Retrievers and Learned Ranking
🎯 Search & query understanding · arXiv · 10 Nov
FERN is a feature-engineered ranking approach for Text-to-SQL table retrieval that replaces large generative models with frozen retrievers and LightGBM rankers. It fuses three frozen retrievers into 100 candidate tables, describes each with up to 120 features, and reorders them using rankers fitted on training data. On Spider, its candidate pool matches published Claude 3.5-based recall while avoiding expensive generative calls.
Why it matters: Useful for large-scale catalog search and query understanding pipelines, offering high table recall with lower computational overhead than LLM keyword extraction.
