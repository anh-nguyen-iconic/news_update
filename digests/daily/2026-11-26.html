Verifiable Social Reasoning for LLM Assistants

8h ago

Google Research introduces a new evaluation framework that quantifies how well LLM assistants understand social situations based on subjective user narratives. The approach uses multi-agent simulations where a target agent has a hidden motive, and the evaluated assistant must infer this motive solely from a user persona's biased recounting. What is new is establishing a verifiable ground truth for subjective everyday social interactions. Findings reveal that relying on subjective user mediation complicates social reasoning, models are overly sensitive to user framing, and longer conversations can cause models to anchor to prior exchanges rather than leverage clarification.

Key ideas
1 Use multi-agent simulations to establish a verifiable ground truth by assigning a controllable hidden motive to a target agent in a social scenario.
2 Simulate user-mediated reality where the evaluated LLM assistant acts as an observer relying strictly on a single user persona's subjective, potentially biased narrative.
3 Parameterize user personas along distinct cognitive filters (such as confident or insecure) to test model sensitivity to explicit framing and biases.
4 Utilize a five-step evaluation pipeline—grounding in topics, generating templates, running simulations, conducting assistant debriefs, and assessing decisions with an LLM judge.
📊 Results
The researchers applied the framework to 12 LLMs and released an open-sourced dataset containing over 20K generated examples for running experiments.
🛍 How to apply at THE ICONIC
  • Evaluate customer-facing LLM shopping assistants or chatbot agents to ensure they remain objective rather than amplifying user frustrations or subjective shopping biases.
  • Test how well recommendation or stylist agents handle incomplete or skewed user descriptions regarding size, fit, and style preferences.

TaskBridge: Technical Report for SIGIR 2026 eCommerce Challenge

27 Oct · Shandong University
Figure 1. Overall workflow of TaskBridge. The product corpus is first converted into catalog phrase resources. The two Phrases nodes in the figure correspond to (a) and (b): the former is used to construct semantic anchors, whereas the…

TaskBridge is a catalog-anchored query reformulation framework designed for task-oriented e-commerce search, where user queries describe activities or goals rather than specific products. The approach bridges the lexical gap between task intent and product catalogs using three main modules: Catalog Semantic Anchoring, Unified Five-Candidate Rewriting, and Protocol-Aware Selection. The system generates multi-perspective candidate queries, scores them using a BM25 retrieval and reranking proxy, and selects either a single optimal query or multiple complementary queries. Experiments show that TaskBridge effectively improves product retrieval, achieving first place in the SIGIR 2026 eCommerce Challenge.

Key ideas
1 Construct a title phrase lexicon and a corpus-derived phrase lexicon from product catalog text to ground abstract task queries in actual inventory vocabulary.
2 Generate five distinct candidate reformulations incorporating original-query protection, multi-round feedback, multi-role intent prompting, and lexical constraints.
3 Use a protocol-aware selection mechanism combining BM25 retrieval, reranker scoring, and weighted Jaccard overlap to select single or diverse multi-query sets.
📊 Results
In the Closed Phase, TaskBridge achieved Task Completion NDCG@10 of 0.27, Essential Product Recall@100 of 0.16, and MAP of 0.11 under the Automatic setting, and 0.31, 0.18, and 0.12 under the Interactive setting.
🛍 How to apply at THE ICONIC
  • Implement catalog semantic anchoring to map natural language lifestyle or activity queries (e.g., 'beach holiday outfit') to THE ICONIC's actual product taxonomy.
  • Use multi-candidate query rewriting and reranking proxies to improve sparse keyword search (BM25) recall for complex customer search intents.

The system allows users to search for products, compare alternatives, receive recommendations, and manage shopping carts entirely through natural speech. pmndre/pine

10 Nov · ⭐ 558

Pine is a reactive AI agent framework and command-line tool designed to trigger agent workflows from arbitrary external stimuli like folders, webhooks, and commands rather than relying purely on manual chat inputs. It features an event-driven architecture, zero-user-config administration via tool calls, and self-discovery tools that look up APIs on demand using BM25. The platform supports complex orchestration including swarms, parallel sub-agents, and shared task boards. It provides a terminal UI, cross-platform desktop apps, and mobile/web access.

Key ideas
1 Event-driven architecture: Agents subscribe to custom TypeScript event sources with schemas to react automatically to stimuli like file changes, FTP endpoints, and webhooks.
2 Zero-config setup: The main agent configures settings, MCPs, and event sources dynamically through administrative tool calls rather than manual file editing.
3 Self-discovery via BM25: Agents look up internal details and APIs on demand instead of cluttering their context windows with complete documentation.
4 Swarm and board orchestration: Supports coordinated multi-agent workflows where a lead agent delegates tasks to parallel sub-agents via shared progress boards.
📊 Results
No quantitative results reported.

Jointly Optimizing Debiased CTR and Uplift for Coupons Marketing: A Unified Causal Framework

6 Nov
Figure 2. Overview of UniMVT, consisting of: (i) a DCR layer that disentangles treatment-sensitive and confounding features via MoE; and (ii) an HTE network for jointly estimating base CTR, latent uCATE, and intensity-dependent uplift.…

Marketing interventions such as discount coupons introduce confounding bias into click-through rate (CTR) prediction by mixing users' intrinsic preferences with intervention-induced uplift. The authors propose the Unified Multi-Valued Treatment Network (UniMVT), which integrates a Deconfounded Causal Representation layer with a Counterfactual X-Network to disentangle invariant confounders from treatment-sensitive features. UniMVT utilizes a latent unit sensitivity formulation to handle multi-valued treatment intensities and enforce a monotonic linear shift in the logit space. Extensive experiments on synthetic benchmarks and industrial data demonstrate that the framework achieves superior predictive accuracy, calibration, and optimal coupon allocation. Real-world A/B tests confirm significant improvements in online revenue and return on investment.

Key ideas
1 Deconfounded Causal Representation (DCR) layer uses a Mixture-of-Experts architecture to disentangle baseline preferences, shared confounders, and intervention-sensitive features, preventing gradient leakage through stop-gradient operators and orthogonality penalties.
2 Latent Unit Sensitivity (uCATE) formulation models treatment intensity via a monotonic linear shift strictly within the logit space to capture non-linear saturation effects without violating probability bounds.
3 Counterfactual X-Network bridges observational gaps by employing an auxiliary intensity estimation head to impute feasible dosages for the control group and regularizing counterfactual predictions with factual labels using MSE loss.
4 Treatment-Aware Gate (TA-Gate) dynamically modulates feature processing pathways across multiple hidden layers using context-dependent scaling derived from treatment embeddings, avoiding simple feature concatenation.
📊 Results
Evaluated on synthetic datasets (80,000 training and 8,000 test samples) and an industrial dataset from Kuaishou live-stream coupon traffic. Online A/B tests on 10% of production traffic showed an 18.14% increase in coupon revenue, an 8.80 improvement in ROI, and a reduction in coupon PCOC error by 86.51%.
🛍 How to apply at THE ICONIC
  • Personalise promotional discount offers and coupon face values across fashion and lifestyle categories by deploying UniMVT to balance base customer purchase intent against price sensitivity.
  • Improve recommendation ranking calibration by disentangling user intent from marketing interventions in homepage tile personalisation and CRM marketing campaigns.
  • Optimise marketing spend and campaign ROI constraints by leveraging predicted unit sensitivity and counterfactual estimation to decide whether to issue a discount voucher or withhold treatment.
Topics: Ads & retail media · Customer behaviour & intent modelling · Fraud, abuse & trust
